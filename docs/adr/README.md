# Architecture Decision Records

ADR används för att dokumentera större arkitekturbeslut och varför de fattades.

Exempel:

- val av autentiseringslösning,
- större teknikval,
- integrationsarkitektur,
- datalagringsstrategi,
- större avsteg från projektets etablerade arkitektur.

ADR behövs inte för normala små utvecklingsbeslut.

## Filnamn

Använd:

`001-short-decision-name.md`

`002-short-decision-name.md`

## Struktur

Varje ADR ska vara kort och följa:

```md
# [Beslutets namn]

## Status

Proposed / Accepted / Superseded / Deprecated

## Sammanhang

Vilket problem eller behov ska lösas?

## Beslut

Vad har vi beslutat?

## Konsekvenser

Vilka viktiga positiva eller negativa konsekvenser får beslutet?
```
